# Steps To The Stars

**Steps To The Stars** is a hand-crafted single-player puzzle adventure following the journey of two fallen stars as they climb to return to the constellation from which they have fallen.

Little Star has lost his shine and must rely on Big Star to guide him safely through the shadows. Using Big Star’s strength, the pair push blocks, press buttons, clear paths and solve environmental puzzles together in the hope of returning to the heavens.

## Status

This repository contains the Unreal Engine 5 project files for **Steps To The Stars**.

The original prototype was created as part of the Staffordshire University Junior/Senior Collaboration project and has since become the basis for a commercial game project.
